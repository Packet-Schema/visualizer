# 開発サーバー起動

このリポジトリの開発サーバーは `web` ディレクトリで起動します。開発サーバーを使うときは、`web` に移動してから `npm` スクリプトを実行します。

## 実行手順

1. `web` ディレクトリへ移動する。
2. `npm run dev` を実行して開発サーバーを起動する。
3. 起動後は、表示されたローカル URL やポート番号を確認して共有する。

## コマンド

```bash
cd web
npm run dev
```

## 補足

- `web/package-lock.json` があるため、パッケージマネージャーは `npm` を使う。
- 起動に失敗した場合は、主要なエラー内容と不足している前提条件を要約して共有する。
- 長時間実行が必要なため、対話環境ではバックグラウンド実行や別セッション管理を検討する。
